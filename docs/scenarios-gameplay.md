# Scenarios & Gameplay

20 guided scenarios with multi-step objectives across four categories. Each scenario features a
narrative storyline and 3&ndash;4 sequential tasks that guide you through progressively deeper
physics concepts. The six **Cosmic Evolution** scenarios form a connected arc tracing the
universe's history from the quark-gluon plasma through neutron stars and particle colliders.

## Multi-Task System

Each non-sandbox scenario has multiple sequential tasks. As you complete each task:

1. **Narrative text** fades in, providing story context for the next objective
2. The **Goal HUD** updates with the new task and progress counter (e.g., "Task 2/4")
3. **Progress dots** below the HUD show completed, current, and remaining tasks
4. **Hint text** appears below the objective to guide you

When all tasks are complete, the HUD shows **"SCENARIO COMPLETE!"** and the scenario is marked
as finished in the scenario menu.

## Goal HUD

The scenario HUD appears at the top-center of the screen below the stats bar:

- **Active**: `Scenario Name | Task X/Y | Current objective`
- **Task complete**: Blue flash with "Task Complete!" text, auto-advances after 3 seconds
- **All complete**: Green border with "SCENARIO COMPLETE!" text

Narrative text from the storyline fades in and out over 5 seconds when each task begins.
A small **X** button on the right side of the HUD allows ending the scenario early.

## Scenario Cards

The scenario selection menu (accessible from the pause menu) shows:

- Category-colored border and badge
- Scenario name and storyline subtitle
- Description text
- Task count badge (e.g., "4 Tasks")
- Completion checkmark for previously completed scenarios
- **Start** / **Replay** button
