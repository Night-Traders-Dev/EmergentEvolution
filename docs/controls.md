# Controls

| Key | Action |
|---|---|
| `Escape` | Pause menu |
| `F1` | Settings |
| `F2` | Reset simulation |
| `F3` | Spawn Picker |
| `F4` | Select mode |
| `Space` | Pause / unpause |
| `[` / `]` | Halve / double time scale (0.0625&times;&ndash;16&times;) |
| `Alt+Enter` | Toggle borderless fullscreen / windowed |
| `Ctrl+S` / `Ctrl+L` | Save / Load |
| `W A S D` | Pan camera |
| Left drag | Pan camera |
| Scroll wheel | Zoom |
| Left click | Spawn / select / fire / place (context-dependent) |

Gamepad support is automatic when a controller is connected (see [Gamepad Support](ui-visualization.md#gamepad-support)).
